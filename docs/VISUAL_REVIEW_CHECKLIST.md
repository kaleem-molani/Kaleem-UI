# Visual Review Checklist

Use this checklist for the M0 preview and every meaningful design-system
release.

## Identity and hierarchy

-   [ ] Evergreen and mint are used intentionally.
-   [ ] Primary actions are distinguishable without overpowering the
    page.
-   [ ] Page title, section headings, labels, and metadata have clear
    hierarchy.
-   [ ] The page communicates its purpose without decorative filler.

## Layout and density

-   [ ] Content aligns to a consistent grid.
-   [ ] Spacing follows the documented scale.
-   [ ] Cards are used only when grouping or separation is useful.
-   [ ] Balanced density is maintained at desktop and mobile widths.
-   [ ] Long content, tables, and forms do not overflow.

## Theme and accessibility

-   [ ] Light and dark themes are readable.
-   [ ] Text and controls meet applicable contrast requirements.
-   [ ] Focus is visible.
-   [ ] Keyboard interaction works.
-   [ ] Errors and statuses are not communicated by color alone.
-   [ ] Reduced-motion preference is respected.

## Interaction and state

-   [ ] Hover, active, focus, disabled, and loading states are present
    where relevant.
-   [ ] Dialogs and menus manage focus and dismissal correctly.
-   [ ] Empty, loading, error, and populated states are considered.
-   [ ] Theme switching behaves predictably.

## Anti-slop review

-   [ ] No unnecessary gradient or decorative blobs.
-   [ ] No repeated cards without a content reason.
-   [ ] No meaningless badges or icons.
-   [ ] No fabricated metrics or testimonials.
-   [ ] No animation without a clear purpose.
-   [ ] The layout follows the task rather than a generic dashboard
    template.

## Evidence

-   [ ] Desktop screenshot captured.
-   [ ] Mobile/narrow screenshot captured.
-   [ ] Any visual diffs reviewed.
-   [ ] Remaining defects documented.
